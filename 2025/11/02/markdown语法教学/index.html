markdown语法教学

什么是markdown语法？

Markdown 是一种轻量级标记语言，用简单的符号标记文本格式，无需复杂排版操作就能生成结构化文档。

它的核心价值在于 “易读易写”，既适合日常记录（如笔记、待办），也能用于创作（如文章、报告），且生成的内容可轻松转换为 HTML、PDF 等格式。

核心优势

  1. 语法简单：仅需记住十几个基础符号，几分钟就能上手。
  2. 跨平台兼容：几乎所有笔记软件（如 Notion、Obsidian）、写作平台（如知乎、GitHub）都支持 Markdown。
  3. 专注内容：无需频繁点击格式按钮，用符号就能快速设置标题、列表等，减少排版干扰。
